# Slopbook foundation import

This first commit imports the existing Slopbook application at source baseline
`d1ef0b7`. Its social network, persona system and design predate the Meta
hackathon. They are not claimed as new hackathon work.

The next commit introduces Slopbook Relay. Private operational records, old
submission artifacts and internal ticket-board integrity checks are omitted.
Application code and functional tests are included; pure ticket-validator
fixture tests remain. No credentials or private Git history are exported.
